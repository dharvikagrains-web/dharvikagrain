## 2. 📊 Google Analytics 4 (GA4) & Google Search Console

### Step A: Connect Google Analytics
1. Go to [analytics.google.com](https://analytics.google.com) and create a property: **Dharvika Grains**.
2. Create a **Web Data Stream** with URL `https://dharvikagrains.in`.
3. Copy your Measurement ID (`G-XXXXXXXXXX`).
4. In your `.env.local` or hosting provider environment variables (Vercel / Cloudflare), set:
   ```bash
   NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
   ```
   *(The app will automatically inject the official Google gtag scripts without any manual code changes!)*

### Step B: Google Search Console Submission
1. Go to [search.google.com/search-console](https://search.google.com/search-console).
2. Add property: `https://dharvikagrains.in` (URL prefix or Domain).
3. If using HTML meta tag verification, copy the verification token and set:
   ```bash
   NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=your-verification-code
   ```
4. Once verified, click **Sitemaps** in the left menu and enter:
   ```text
   https://dharvikagrains.in/sitemap.xml
   ```
   This immediately submits all 89 storefront pages, recipes, and journal guides to Google's crawler.

## 4. 🔒 HTTPS Padlock & Security

Your Next.js configuration is now fortified with strict production security headers:
- `Strict-Transport-Security` (HSTS): `max-age=63072000; includeSubDomains; preload`
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: SAMEORIGIN`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy: camera=(), microphone=(), geolocation=()`

**DNS & SSL Checklist:**
- Point your domain `A` or `CNAME` records to your hosting platform (Vercel / Cloudflare).
- Both Vercel and Cloudflare issue free, automated Let's Encrypt / DigiCert SSL certificates that renew automatically.
- Ensure **Always Use HTTPS** is toggled ON in Cloudflare or Vercel.

## 5. 💳 Razorpay Live Payment Gateway Setup

When ready to switch from sandbox/simulation mode to live payments:
1. Log in to your [Razorpay Dashboard](https://dashboard.razorpay.com).
2. Switch toggle to **Live Mode**.
3. Go to **Account & Settings -> API Keys** and generate Live Keys.
4. Update your production environment variables:
   ```bash
   NEXT_PUBLIC_RAZORPAY_KEY_ID=rzp_live_xxxxxxxxxxxxxx
   RAZORPAY_KEY_ID=rzp_live_xxxxxxxxxxxxxx
   RAZORPAY_KEY_SECRET=your_live_secret_key
   RAZORPAY_WEBHOOK_SECRET=your_live_webhook_secret
   ```
5. In Razorpay Webhooks, add endpoint: `https://dharvikagrains.in/api/payments/webhook` with events:
   - `payment.captured`
   - `payment.failed`
   - `order.paid`
